# Вологда по эпохам

3D-карта 17 тысяч зданий Вологды, раскрашенных по году постройки, в неоновом стиле 80-х: три эпохи (старый город, советский период, новая Вологда), машины и пешеходы на настоящих улицах, мосты, набережные, рельеф и закатное небо.

Что можно делать:

- Смотреть слои истории: храмы, деревянное наследие, памятники под охраной, стили, дома со статьями в Википедии. У каждой истории есть источник.
- Строить пешую прогулку по историям («Прогулка») и открывать её в Google Картах.
- Смотреть граф людей, событий и организаций, связанных с домами («Граф»).
- Решать квесты: загадки, ответ на которые нужно найти на карте («Квесты»).
- Сесть за руль (F): задания (M) — масло в Кремль, такси, гонка по кольцам, развоз кружева; радио (Q/E).
- Достраивать город в режиме «Стройка» (B): зоны, дороги, бюджет, жители, снос. Город сохраняется в браузере.

Пасхалка: набери на клавиатуре `1147`.

Сайт статический: файлы из корня репозитория раздаются через GitHub Pages. Локально — `python -m http.server 8643` в этой папке.

Данные: OpenStreetMap (ODbL), © CARTO, рельеф Terrarium (Mapzen, AWS Open Data), годы постройки — «How old is this house» (Кон-Тики), истории и связи — Wikidata (CC0) и Википедия (CC BY-SA), фото — Wikimedia Commons (автор и лицензия указаны у каждого фото).
