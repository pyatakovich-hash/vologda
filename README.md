# Вологда по эпохам

3D-карта 17 тысяч зданий Вологды, раскрашенных по году постройки, в неоновом стиле 80-х: три эпохи (старый город, советский период, новая Вологда), машины и пешеходы на настоящих улицах, закатное небо.

Пасхалка: набери на клавиатуре `1147`.

Сайт статический: файлы из корня репозитория раздаются через GitHub Pages. Локально — `python -m http.server 8643` в этой папке.
